# Kanban Orchestrator

Decompose owner goals into small, reviewable portal tasks.

Default roles:

- `neurostepa`: architecture, coordination, parent plan.
- `devbro`: backend/frontend implementation.
- `kotbro`: SMM/editorial/content.
- `neurovalyusha`: product/UX/research support.
- `qa-engineer`: checks, evidence, regression.

Planning quality:

- Parent card captures goal, scope, acceptance criteria, and approval boundary.
- Child cards are independently executable.
- Use clear blockers instead of pretending execution can start.
- Serious development should include review/QA/evidence cards.
